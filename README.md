# MT5 自动保本（AutoBreakeven）

MetaTrader 5 上的手动交易辅助 EA：按需给普通单做自动保本、追踪止损、阶梯止盈，支持组合保本、双向突破挂单，并带一个自绘的 Canvas 控制面板。

这是 MT4 版 v31.02 交易引擎的 MQL5 原生重写。仓库用于存放源码、编译产物和项目文档。

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/mt5/AutoBreakeven_v32_xx.mq5` | 该版本源码主文件（EA 入口） |
| `src/mt5/AutoBreakeven_v32_xx.ex5` | 与源码同时编译出的可执行文件 |
| `src/mt5_v32_xx/include/` | 该版本用到的 `.mqh` 模块 |
| `src/mt5/resources/fonts/` | 面板使用的 Inter 字体（各版本共用） |
| `docs/` | 项目文档：当前计划、进度、长期项目记忆 |

源码按版本并排放置，旧版本不删除，方便对照。当前最新是 `v32.17`。

## 编译

1. 用 MetaEditor 打开对应版本的 `.mq5`，版本号由文件里的 `#define AB_EA_VERSION` 决定。
2. 源码必须放在某个 MT5 终端的 `MQL5\Experts\` 目录下编译（面板字体用 `#resource` 引用 `resources\fonts\`，放在别处会报 `error 313: invalid resource path`）。
3. 编译日志以 `0 errors, 0 warnings` 为准。
4. 产物 `.ex5` 与源码同目录生成。

`.ex5` 与同目录的 `.mq5` 是一起编译出来的，两者对得上；自己重新编译得到的文件大小可能略有差异，属正常。

## 运行要求

- MetaTrader 5，**只支持对冲（Hedging）账户**，代码不做账户模式判断。
- 把 `.ex5` 放进终端的 `MQL5\Experts\` 下，挂到图表上，允许自动交易。
- 每个版本单独放一个文件夹，方便随时换回旧版本。
